Full candidate list and guidance lives in the repo at
`cursor-claude-common/references/chapter-card-title-suggestions.md` (shared with Cursor) — read that file
for the complete list before authoring a new `Chapter` card.

Quick summary: chosen pair for `greetings/adults` is **"Watch & Learn"** (before video) / **"Keep Going to
Finish"** (after video, before standalone practice questions). Key rule to remember: never call a post-video
segment "practice" if the video itself already contained interactive quiz questions (as with the
`VideoConversation` template) — it wrongly implies the video part wasn't already quizzing the player. Use
something like "A Few More Questions" or "Keep Going to Finish" instead.
