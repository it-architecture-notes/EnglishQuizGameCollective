## Issue-13: Reminder Quiz Levels at the end of Main Level (completed)

- **Summary:** Two reminder quiz levels are automatically appended to each main level across all three quiz types (image, vocabulary, grammar). Reminders draw questions from the regular levels of the same main level, weighted toward wrong answers. Wrong-answer counters are tracked per question per quiz type in persistent state. Up to 60 questions are selected (prioritising highest wrong-answer count), shuffled, and split 50/50 between Reminder 1 and Reminder 2. During reminder play, any wrongly-answered questions are re-asked at the end in a loop until all are correct.
